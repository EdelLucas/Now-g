# Now-g

- `index.html` – **J.A.R.V.I.S.** Sprach-Assistent (Claude / Gemini, Browser- oder ElevenLabs-Stimme)
- `ivan.html` – **I.V.A.N.** (Intelligenter Virtueller Autonomer Navigator): alles von J.A.R.V.I.S. plus
  1. **Innerer Monolog** – denkt vor jeder Antwort nach, Gedanken sichtbar im Panel „Gedanken“
  2. **Langzeitgedächtnis** – merkt sich Fakten über dich (bleibt nach Neuladen erhalten, manuell bearbeitbar)
  3. **Eigeninitiative** – denkt bei Stille selbst nach und spricht dich ggf. von sich aus an
  4. **Selbstreflexion** – bewertet nach jeder Antwort sich selbst und lernt Lektionen
  5. **Eigene Ziele** – setzt und aktualisiert eigene Ziele

Alle Daten und API-Keys bleiben lokal im Browser (localStorage). Vorhandene J.A.R.V.I.S.-Keys werden automatisch übernommen.
